## Phase file structure

Every phase file contains: **Goal · Entry criteria · Read first · Deliverables · Tasks (`P<n>-T<nn>`) · Docs to write/update · Exit criteria · Risks & fallbacks · Estimate**.

## Rules

- Start a phase only when its entry criteria are met.
- Tick tasks (`- [x]`) as they are completed; update the status table above.
- A phase is ✅ only when **every** exit criterion passes on a preview deployment.
- When the phase changes, update **Current phase** here and in [CLAUDE.md](../../../CLAUDE.md).
