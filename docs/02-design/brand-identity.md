## 1. Name

**Sprigkit** (D-5). Always written with one capital S, as one word. Never "SprigKit", "Sprig Kit" or "sprigkit" in prose (lowercase only in the domain and code).

## 2. Personality

From the art direction "precision instrument" (design-system §1): **calm, exact, confident, tactile, honest.** Sprigkit sounds like a well-made tool, not a startup. It does not shout, hype or use exclamation marks.

## 3. Tagline and positioning line

| Use | Text |
|---|---|
| Tagline (footer, About) | Private tools that run in your browser. |
| Proof line (footer, privacy strip) | Your files never leave your device. |
| Meta description base | Private, browser-based PDF, image and developer tools. Nothing is uploaded. |

Final homepage headline is written in Phase 7 ([content-voice-ux-copy.md](content-voice-ux-copy.md)).

## 4. Logo

### 4.1 Mark

A **sprig**: a vertical stem with two offset leaves and a single round bud. It is drawn on the 24px Lucide grid with the same 1.5px round-cap stroke as the interface icons, so the logo belongs to the same family as every icon on the page (design-system §6).

- The **bud is the only accent-coloured element** (`--accent`): it echoes the "one accent" rule and the "signal" in the UI.
- Stem and leaves use `currentColor` (`--fg`), so the mark works in both themes.
- Source: `LogoMark` in `src/components/brand/Logo.tsx`.

### 4.2 Wordmark

"Sprigkit" set in **Geist Sans**, weight 600, at `text-h3` with tight tracking. It is live text, not outlines, so it stays sharp, translatable and accessible. Mark and wordmark sit 8px apart (`Logo` component).

### 4.3 App icon and favicon

The mark in paper colour on an ink rounded square (radius 5.5 on 24, about 23%), bud in the dark-theme accent. One tile design works on light and dark browser chrome.

| File | Size | Generated by |
|---|---|---|
| `src/app/icon.svg` | vector (source) | hand-authored |
| `src/app/favicon.ico` | 16, 32, 48 px | `node scripts/generate-icons.mjs` |
| `src/app/apple-icon.png` | 180 px | same script |
| `public/icons/icon-192.png`, `icon-512.png` | 192, 512 px | same script (for the web app manifest, Phase 7) |

A maskable icon (safe-zone padding) is added with the manifest in Phase 7.

Colours in the icon files are the hex equivalents of the tokens: ink `#1e1a15` (`--fg` light), paper `#fbfaf7` (`--bg` light), bud `#f77e35` (`--accent` dark).

### 4.4 Usage rules

- Minimum size: mark 16px; mark + wordmark 96px wide.
- Clear space: at least the bud's diameter on every side.
- Do not recolour the leaves, add gradients, outlines, shadows or animate the mark.
- Do not place the mark on the accent colour (the bud disappears).

## 5. Licensing
